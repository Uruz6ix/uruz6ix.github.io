Noto Sans SC variable font, sourced from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notosanssc

`noto-sans-sc-ui.woff2` is a local subset of `NotoSansSC[wght].ttf`, containing ASCII, interface Chinese characters, and the interface symbols. Weight variation is preserved. The original SIL Open Font License is included in `OFL.txt`.

Rebuild with `scripts/subset-watercolor-font.py` when adding new Chinese interface text. The font is loaded from this website, without requesting a remote font service at runtime.

The interface's `--cool-grey-20: #d3d7de` is a digital visual approximation inspired by Prismacolor's Cool Grey 20% pencil, not an official manufacturer sRGB measurement.
